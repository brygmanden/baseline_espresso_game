# Baseline Testing levels

Copy of the six game levels from [jembarista/Baseline-Testing](https://github.com/jembarista/Baseline-Testing) (commit `525e0ed`). Open `single-espresso.html` to start at Level 1.

Levels 1, 2 and 4 (`single-espresso.html`, `long-black.html`, `manual-dose.html`) use the new illustrated stage in `assets/`: the bar background at full size (2000×1513), with the espresso machine, grinder, portafilter and tamping mat all placed at the same 0.327 scale. The cup image (`assets/cup.png`) uses the same scale. The tamper and distributor images also use it. The knock tube and towel are still drawn shapes, placed and sized to match the stage, until their image files are added. Levels 3, 5 and 6 are unchanged from the source repo because they need a two-group machine.

The source repo's `completion.html` and its image are not included, so passing Level 6 leads to a missing page.
