# Black Friday Espresso Score

A standalone, single-level version of the Baseline espresso game: make one espresso, with every step done, in 25 seconds or less.

Open `index.html` to play. It needs no build step; all artwork is in `assets/`.

It is a copy of Level 1 (`../baseline-testing/single-espresso.html`) with the level picker and the link to Level 2 removed.
