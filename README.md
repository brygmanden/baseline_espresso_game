# Baseline: Work the Bar

An interactive espresso workflow game. Pull four single espressos from a two-group machine in under 50 seconds. Open `index.html` in a browser to play. It needs no build tools or installation.

## How to play

- Drag a portafilter to a station, or tap it and then tap the station.
- The clock starts when the first portafilter leaves its group. It stops when both shots are running.
- Each portafilter needs nine steps: knock out, flush the group, wipe, grind, weigh, distribute, tamp, lock in, and brew.
- The grinder runs hands-free for 7 seconds. Your hands do one job at a time, so overlap the work across both handles.
- Set the cups under each group before the coffee starts to flow, 6.5 seconds after the pump starts.
- A run counts as valid when every step is done and each pump starts within 1 second of locking in.

## Publish with GitHub Pages

1. Open the repository's Settings, then Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Choose `main` and `/ (root)`, then Save.
4. When deployment finishes, share the site link shown in the Pages settings.

## Prototype notes

- Action timings are fixed and illustrative. This is a practice drill, not an exam certification tool.
- Your best valid time is saved in your own browser only.
- Fonts load from Google Fonts. Without a connection, the game falls back to system fonts.
- Landscape is the best layout on phones. Testing on physical devices is still recommended.
